0. 시험 직전 체크리스트

  • 마스터 정리 답안은 단계별로 쓴다 (결과만 쓰면 감점)
    ① 일반형 ② a, b, f(n) ③ a ≥ 1, b > 1 확인 ④ 기준값 n^(log_b a) ⑤ 케이스 판별 (Case 3이면 정규성 조건) ⑥ 결론
  • T(n) = T(n−1) + n → 마스터 정리 적용 불가 → 직접 펼쳐서 Θ(n²)
  • O / Ω / Θ / o 정의를 c, N을 써서 쓸 수 있는가
  • 극한으로 차수 판정: 상수 → Θ, 0 → o, ∞ → 반대 방향 o
  • Partition 손 추적: 마지막 pivot swap 빼먹지 말기
  • Prim을 distance / nearest 배열로 추적, Θ(n²)인 이유
  • MST ≠ 최단경로 (Prim의 distance ≠ Dijkstra의 distance)

1주차 — 알고리즘이란 (Ch.1.1)

  • 알고리즘: 문제를 푸는 명확하게 정의된 유한한 단계. 입력 → 처리 → 출력
  • 핵심 성질 4가지: 정확성 · 유한성 · 명확성 · 효율성
  • 품질 4요소: 정확성 · 효율성 · 견고성(Robustness, 엣지 케이스·입력 검증) · 명확성(Clarity)
  • 의사코드는 특정 언어에 독립적. Max(A[1..n])의 비교 횟수 = n−1회 → O(n)

100만 건평균 50만 번 비교최대 약 20번

2주차 — 복잡도와 점근 표기 (Ch.1.2~1.4)

  • Basic operation: 수행 시간을 대표하는 핵심 연산 (정렬은 비교, 합산은 덧셈). 실제 시간 대신 연산 횟수로 추상화
  • basic operation 1ns, 입력 10억이면 이차 알고리즘 ≈ 31.7년, n ln n 알고리즘 ≈ 29.9초
  • 공간복잡도: sum, i 같은 변수만 쓰면 O(1), 크기 n 배열을 추가하면 O(n)
  • for i=1..n: for j=i+1..n: count++ → 횟수 n(n−1)/2 → O(n²)
  • Order는 최고차항만 본다: 3n+7 → n, 5n³+n²+100 → n³
  • 100n vs 0.01n²: n < 10,000이면 이차식이 더 빠를 수 있음

⭐⭐ 점근 표기 정의

  • Theorem 1.2: g ∈ o(f) ⇒ g ∈ O(f) − Ω(f)

3주차 — 분할정복: 이진 탐색, 합병 정렬 (Ch.2)

  • 분할정복 3단계: Divide(같은 구조의 작은 문제로) → Conquer(재귀로 해결) → Combine(합침). 이진 탐색은 Combine이 거의 없음
  • 이진 탐색: T(n) = T(n/2) + c → Θ(log n)
  • 정렬돼 있어야 "가운데보다 크면 왼쪽엔 없다" → 절반을 버릴 수 있음
  • [3,7,11,18,25,31,42,56,63,77,81]에서 42 찾기: mid 값 31 → 63 → 42 (3번)
  • 합병 정렬: Divide는 쉽고 Combine(merge)이 핵심. merge는 두 포인터로 Θ(n)
  • T(n) = 2T(n/2) + cn → 레벨마다 cn × 레벨 log n개 = Θ(n log n) (항상)
  • 추가 메모리 O(n). 비교 기반 정렬 하한 Θ(n log n) → 점근적으로 최적

퀵 정렬

  • Hoare(1960). Pivot 기준으로 작은 것 왼쪽 / 큰 것 오른쪽 → pivot은 최종 위치 확정 → 양쪽 재귀
  • 분할(partition)이 핵심, 결합 없음 (합병 정렬은 분할이 단순하고 merge가 핵심)
  • 중앙값을 pivot으로 못 쓰는 이유: 중앙값을 알려면 정렬해야 하는데 지금 정렬 중이라서
partition(A, low, high):
    pivot ← A[low]; j ← low
    for i ← low+1 to high:
        if A[i] < pivot: j ← j+1; swap(A[i], A[j])
    swap(A[low], A[j])          // 마지막 pivot swap
    return j
  • 수업 추적: [7,2,1,6,8,5,3,4], pivot 7 → [4,2,1,6,5,3,7,8], 7은 인덱스 6

5주차 — DP: 이항계수, Floyd (Ch.3.1~3.2)

  • 같은 부분 문제가 반복되면 저장해서 재사용 (메모이제이션 top-down / 테이블 bottom-up)
  • 적용 조건: 최적 부분 구조 + 중복 부분 문제
  • 설계 4단계: 상태 정의 → 점화식 → 초기값 → 계산 순서
  • 분할정복의 부분 문제는 독립적, DP의 부분 문제는 겹침

이항계수

B[i][j] = B[i−1][j−1] + B[i−1][j]   (0 < j < i)
B[i][0] = B[i][i] = 1
  • 순수 재귀는 지수 시간(중복 계산), DP는 Θ(nk), 1차원 배열로 공간 O(k) 가능 (j를 역방향으로)
  • C(6,3) = 20

⭐⭐ Floyd(-Warshall)

D⁽ᵏ⁾[i][j] = min( D⁽ᵏ⁻¹⁾[i][j],  D⁽ᵏ⁻¹⁾[i][k] + D⁽ᵏ⁻¹⁾[k][j] )
D⁽⁰⁾ = 인접 행렬 W (i=j면 0, 간선 없으면 ∞)
  • 3중 루프에서 k가 반드시 가장 바깥. 이유: D⁽ᵏ⁾를 구하려면 D⁽ᵏ⁻¹⁾가 완전히 완성돼 있어야 함
  • 시간 Θ(n³), 공간 Θ(n²). in-place 가능: k단계에서 k행·k열은 안 바뀜
  • 음수 간선 처리 가능, 음수 사이클은 끝난 뒤 D[i][i] < 0으로 감지만 가능
  • 예제(1→2:3, 1→4:7, 2→3:2, 2→4:5, 3→4:1): k=2에서 D[1][3] = 5, k=3에서 D[1][4] = 6, D[2][4] = 3

6주차 — DP 최적화: 연쇄행렬곱셈, 최적 BST (Ch.3.3~3.5)

  • 최적화 문제: 가능한 해(feasible solution)가 여러 개이고 그중 비용 최소 / 이익 최대를 찾는 문제
  • 최적성의 원리: 문제의 최적해는 부분 문제의 최적해를 포함한다. 이게 성립해야 DP 적용 가능

⭐⭐ 연쇄행렬곱셈

  • A_i의 크기 = d[i−1] × d[i]. (p×q)·(q×r) 곱셈 = p·q·r번
  • d = [10, 100, 5, 50]: (A1A2)A3 = 7500 / A1(A2A3) = 75000
  • 괄호 방법 수는 카탈란 수 → 지수적
M[i][i] = 0
M[i][j] = min_{i ≤ k < j} ( M[i][k] + M[k+1][j] + d[i−1]·d[k]·d[j] )
  • P[i][j] = 최소를 만든 k (괄호 복원용)
  • diagonal 순서(구간 길이 짧은 것부터)인 이유: M[i][j]는 더 짧은 구간 값만 참조. "DP는 계산 순서가 곧 알고리즘 구조다"
  • 복잡도: 부분 문제 O(n²) × 분할점 O(n) = O(n³) 시간, O(n²) 공간

⭐ 예제: d = [5, 2, 3, 4, 6]

계산결과

M[2][3] = 2·3·424
M[3][4] = 3·4·672
M[1][3] = min(k=1: 0+24+5·2·4, k=2: 30+0+5·3·4)64, P = 1

  • 복원은 P만 따라감 → O(n). 계산(O(n³))과 복원은 별개 알고리즘

⭐⭐ 최적 이진탐색트리

  • 평균 탐색 비용 Σ pᵢ·(깊이ᵢ + 1) 최소인 BST. (깊이+1) = 비교 횟수
  • 최적 BST ≠ 균형 BST. 자주 찾는 키를 루트 가까이
  • Greedy(빈도 최대를 루트로)로는 전역 최적 보장 안 됨 → DP 필요
A[i][j] = 0                (i > j, 빈 구간)
A[i][i] = pᵢ
A[i][j] = min_{i ≤ k ≤ j} ( A[i][k−1] + A[k+1][j] ) + Σ p_m
  • Σp_m을 더하는 이유: 루트 Kₖ 아래 붙으면 부분트리의 모든 키 깊이가 1 증가
  • 연쇄행렬곱과 차이: 분할점 i ≤ k < j vs 루트 i ≤ k ≤ j / 추가 항 d·d·d vs W(i,j)
  • R[i][j] = 최적 루트. 시간 O(n³), 공간 O(n²)

7주차 — Greedy, MST, Prim (Ch.4)

  • Greedy: 매 단계 지금 가장 좋아 보이는 선택 하나를 즉시 확정, 번복하지 않음
  • 최적 보장 조건: 탐욕적 선택 속성 + 최적 부분 구조 → 반드시 검증 필요
  • Greedy 예: MST(Prim, Kruskal), 활동 선택, Huffman / 실패 예: 0-1 Knapsack, 최적 BST

Spanning Tree와 MST

  • Spanning Tree: ① 모든 정점 포함 ② 간선 정확히 n−1개 ③ 사이클 없음 ④ 연결됨
  • MST: 모든 spanning tree 중 간선 가중치 합이 최소인 것
  • 연결 그래프에서만 정의 (비연결이면 spanning forest)
  • 가중치가 모두 다르면 MST는 유일, 같은 값이 있으면 여러 개일 수 있음
  • MST ≠ 최단경로(Dijkstra). MST는 전체 연결 비용 최소

⭐⭐ Prim 알고리즘

  • 정점 집합 Y와 V−Y를 잇는 간선 중 최소 가중치를 골라 그 정점을 Y에 추가. Y = V가 되면 종료 (n−1번 선택)
  • "전체 그래프에서 가장 싼 간선"이 아니라 "현재 트리에 연결된 간선 중 가장 싼 것" (전체에서 고르는 건 Kruskal)
  • 근거: Cut Property — Y와 V−Y를 가로지르는 가장 가벼운 간선은 어떤 MST에 반드시 포함됨
  • nearest[i] = Y 안에서 vᵢ와 가장 가깝게 연결되는 정점의 인덱스 (초기 1)
  • distance[i] = vᵢ를 현재 트리에 붙이는 최소 비용 (초기 W[1][i]). −1이면 이미 Y에 포함
repeat (n−1) times:
    min ← ∞
    for i = 2..n:                              // ① 최솟값 탐색 O(n)
        if 0 ≤ distance[i] < min: min ← distance[i]; vnear ← i
    F ← F ∪ {(nearest[vnear], vnear)}          // ② 간선 추가
    distance[vnear] ← −1
    for i = 2..n:                              // ③ 갱신 O(n)
        if W[i][vnear] < distance[i]:
            distance[i] ← W[i][vnear]; nearest[i] ← vnear
  • Prim의 distance = "현재 트리와 v를 잇는 최소 비용" / Dijkstra의 distance = "출발점에서 v까지 최단 경로 비용"
  • 복잡도: (n−1)번 × (O(n) 탐색 + O(n) 갱신) = Θ(n²) (every-case). 교재: T(n) = 2(n−1)(n−1)
  • 이진 힙 O((n+m) log n) → sparse 그래프 유리 / 인접행렬 Θ(n²)는 dense 그래프에 적합

📘 교재 전용 내용 (20%)

Ch.1

  • 입력 값과 상관없이 횟수가 같으면 every-case 분석 T(n)
  • 순차 탐색 평균 (x가 반드시 있고 위치가 균등): A(n) = (n+1)/2
  • 교환 정렬 비교 횟수 every-case T(n) = n(n−1)/2
  • 피보나치: 재귀 버전 계산 항 수 T(n) > 2^(n/2) (지수), 반복 버전 n+1개 (선형)
  • a, b > 1이면 log_a n ∈ Θ(log_b n) — 로그 밑은 차수에 무관
  • b > a > 0이면 aⁿ ∈ o(bⁿ) — 지수 함수는 밑이 다르면 차수가 다름
  • 모든 a > 0에 대해 aⁿ ∈ o(n!)

Ch.2

  • 이진 탐색 최악 W(n) = ⌊lg n⌋ + 1
  • 합병 정렬 최악 비교 횟수 W(n) = n lg n − (n − 1)
  • 퀵 정렬 최악 W(n) = n(n−1)/2, 평균 A(n) ≈ 1.38(n+1) lg n
  • 큰 정수 곱셈: 곱 4번이면 Θ(n²), (x+y)(w+z)를 이용해 곱 3번 → Θ(n^(lg 3)) ≈ Θ(n^1.58)
  • 임계값(threshold): 재귀 알고리즘과 단순 알고리즘의 실행 시간이 같아지는 n
  • 분할정복을 쓰면 안 되는 경우: ① 크기 n 문제를 거의 n 크기 문제 2개 이상으로 나눌 때 → 지수 시간 (예: 재귀 피보나치) ② 크기 n/c인 문제 거의 n개로 나눌 때 → n^Θ(lg n)

Ch.3

  • DP 최적화 문제 3단계: ① 최적해를 주는 재귀 성질 수립 ② 상향식으로 최적값 계산 ③ 최적해 구성
  • 최적성의 원리가 성립하지 않는 예: 최장 단순 경로
  • Floyd 경로 출력: P[i][j] = i→j 최단경로의 가장 큰 인덱스 중간 정점 (없으면 0)
  • 연쇄행렬곱 정확한 횟수: n(n−1)(n+1)/6 ∈ Θ(n³)
  • TSP: 시간 Θ(n²·2ⁿ) — 완전탐색 (n−1)!보다 낫지만 여전히 지수
  • 서열 정렬: 불일치(mismatch) 벌점 1, 틈(gap) 벌점 2, Θ(mn)

Ch.4

  • Greedy 구성 3단계: ① 선택 절차 ② 적정성 검사 ③ 해답 점검
  • 거스름돈: 12센트 동전이 추가되면 16센트를 greedy는 5개, 최적은 3개 (10+5+1)
  • Promising 집합: 간선 집합 F가 어떤 MST의 부분집합이면 promising
  • Lemma 4.1: F가 promising이고 e가 Y와 V−Y를 잇는 최소 간선이면 F ∪ {e}도 promising
